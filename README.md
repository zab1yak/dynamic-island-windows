# Dynamic Island for Windows

A black, animated "island" at the top-center edge of your laptop screen — inspired by the
iPhone Dynamic Island and MacBook notch apps. Music, Pomodoro, water reminders, a file shelf
and a to-do list live inside it.

> **Status:** early development. The first public release will be `v0.1.0`.

## Build from source

Requirements: Windows 10 2004 (build 19041) or newer, [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
git clone https://github.com/zab1yak/dynamic-island-windows.git
cd dynamic-island-windows
dotnet build
dotnet test
```
