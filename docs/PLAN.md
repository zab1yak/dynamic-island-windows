## 0. Разведка и репозиторий
- Репозиторий `zab1yak/dynamic-island-windows`, MIT, `.editorconfig`, `Directory.Build.props`
  (nullable, warnings as errors), `Directory.Packages.props` (центральные версии), `global.json`.
- **Приёмка:** README, LICENSE, ARCHITECTURE.md, PLAN.md, DECISIONS.md в `main`.

## 1. Каркас решения
- Проекты и граф ссылок по ARCHITECTURE §2; Host + DI + Serilog + глобальные обработчики;
  single instance (Mutex + pipe); трей: «Настройки», «Перезапустить», «Выход».
- `JsonStorageService`, `ISettingsService` с миграциями, `IUiDispatcher`, `TimeProvider`.
- **Приёмка:** второй запуск передаёт аргументы первому и завершается; лог пишется с ротацией;
  исключение в UI-потоке залогировано, приложение живо; тесты хранилища и настроек.
- **Риски:** синхронный контекст Host и WPF → Host стартует до `App.Run`.

## 2. Окно острова
- Окно без рамки, `AllowsTransparency`, NOACTIVATE/TOOLWINDOW/TOPMOST, PMv2, выбор монитора;
  `IslandShapeMath` + `Spring` + `AnimationClock`; машина состояний; hover 150/450 мс, клик закрепляет,
  Ctrl+Alt+Space; автоскрытие в полноэкранном режиме.
- **Приёмка:** клики по прозрачной зоне проходят насквозь; нет в Alt+Tab и панели задач; фокус не крадёт;
  в покое `Rendering` отписан; тесты машины состояний, пружины и геометрии.
- **Риски:** нагрузка layered-окна на 4K; хоткей занят → предупреждение; DPI при смешанных масштабах.

## 3. Дизайн-система
- Тема (цвета, типографика, радиусы), Lucide → Geometry через `IconProvider`, `SpringEase`,
  `SquircleBorder`, кнопки, прогресс, кольцо, toggle, поле ввода, точки страниц; витрина в Debug.
- **Приёмка:** витрина показывает все контролы; `THIRD_PARTY_NOTICES.md` с Lucide (ISC).

## 4. Индикаторы состояния
- Батарея, камера/микрофон (реестр + `RegNotifyChangeKeyValue`, NonPackaged), эвристика записи экрана,
  `LiveActivityArbiter`.
- **Приёмка:** точка камеры/микрофона появляется ≤ 1 с; тесты арбитра и парсера ConsentStore.
- **Риски:** формат ConsentStore не документирован → защитный парсинг.

## 5. Медиа
- GSMTC: сессии, метаданные, обложка, бегущая строка, интерполяция позиции, перемотка, prev/play/next,
  переключение сессий, акцент из обложки, визуализатор по пиковому уровню, live activity.
- **Приёмка:** Spotify/браузер/Яндекс Музыка управляются; тесты интерполятора и доминирующего цвета.
- **Риски:** GSMTC после сна; неточный таймлайн браузеров.

## 6. Восстановление последнего трека
- Сохранение каждые 5 с / при смене / паузе / завершении сессии Windows; после старта — карточка
  на паузе; Play → запуск по AUMID, ожидание сессии ≤ 15 с, перемотка.
- **Приёмка:** тесты потока восстановления с фейками; понятное сообщение при неудаче.
- **Риски:** у Win32-плееров AUMID не всегда запускаемый.

## 7. Pomodoro
- 25/5/15, длинный перерыв каждые 4 цикла; хранится `EndsAtUtc`; звук + уведомление; live activity.
- **Приёмка:** тесты фаз и восстановления после перезапуска на `FakeTimeProvider`.

## 8. Вода
- Цель, +250 мл, отмена, напоминания с интервалом, сброс в полночь, история по дням.
- **Приёмка:** тесты полночи, отмены, напоминаний.

## 9. Shelf
- Приём файлов/папок/картинок/текста/Ctrl+V; копия или ссылка; миниатюры Shell; drag-out; контекстное
  меню; автоочистка, лимит размера, защита от path traversal и конфликтов имён; раскрытие при drag к верху.
- **Приёмка:** тесты безопасных имён и конфликтов; ручная проверка drag из Explorer/браузера.
