# Производительность

Цели из постановки: в простое CPU < 1 %, RAM < 150 МБ, никаких таймеров по 16 мс, когда остров
свёрнут и ничего не анимируется.

## Как устроено, чтобы простаивать
- Кадровый таймер (`CompositionTarget.Rendering`) подписан **только пока движутся пружины**, затем отписывается.
- Часы — разовый таймер до границы минуты.
- Индикаторы камеры/микрофона — `RegNotifyChangeKeyValue`, батарея — события WinRT, полноэкранный режим —
  app-bar уведомление + WinEvent. Опроса нет.
- Медиа: позиция — 4 Гц только пока остров раскрыт и трек играет; визуализатор — 20 Гц только пока играет
  и полоски на экране (live-пилюля или раскрытая страница); обновление не присваивается, если уровни не изменились.
- Pomodoro: разовый таймер на конец фазы; тик 1 Гц только пока таймер идёт и остров виден.
- Вода: два разовых таймера (следующее напоминание, полночь).
- Shelf: опрос кнопки мыши и курсора 4 Гц (два системных вызова) для «ловушки» перетаскивания; выключается
  при блокировке сеанса и когда Shelf отключён.
- Скрытые (полностью прозрачные) слои острова получают `Visibility.Hidden`, их анимации (бегущая строка,
  цифры) не рисуются.
- Release: `ConcurrentGarbageCollection=false` (нет фонового потока GC), `TieredPGO`.

## Замеры
Машина разработчика: Windows 11 (build 26300), 8 логических ядер, 1920×1080 при 125 %.
Сборка `Release`, framework-dependent (.NET 10.0.14), все модули включены, музыка не играет,
ничего не перетаскивается. Метод: `TotalProcessorTime` процесса за интервал, `WorkingSet64` и
`PrivateMemorySize64` (PowerShell `Get-Process`).

| Состояние | CPU | Working set | Private bytes | Потоки |
|---|---|---|---|---|
| Свёрнут, 60 с простоя (после 20 с прогрева) | 0,078 % одного ядра (0,010 % всего CPU) | 145,7 МБ | 60,0 МБ | 14 |
| Раскрыт и закреплён, 30 с простоя | 0,052 % одного ядра | 156,8 МБ | 68,6 МБ | — |

Итог:
- **CPU в простое — цель выполнена с большим запасом.**
- **Память:** собственная (private) память процесса — 60–69 МБ. Working set (включает общие страницы
  WPF/.NET, которые делят все .NET-приложения) — 146 МБ в свёрнутом виде, 157 МБ после первого раскрытия
  (загружаются шаблоны всех страниц). Цель «< 150 МБ» выполняется по private bytes и по working set в
  свёрнутом состоянии, но **не** по working set после раскрытия — превышение ≈ 5 %.

Не замерено (нет условий на машине разработчика): работа во время воспроизведения музыки с визуализатором
и при перетаскивании файлов; самостоятельная (self-contained) сборка из установщика; 60 fps при 4K/200 %.
Эти пункты вынесены в [QA_CHECKLIST.md](QA_CHECKLIST.md).

## Сон, смена пользователя, мониторы
- `PowerModeChanged → Resume`: пересчёт позиции, часов и полноэкранного режима; переподключение к медиасессиям;
  проверка смены дня у «Воды»; Pomodoro считает остаток от сохранённого времени окончания.
- `SessionSwitch`: при блокировке/отключении — остановка «ловушки» перетаскивания; при возврате —
  перепозиционирование и проверка полноэкранного режима.
- Отключение монитора: `DisplaySettingsChanged` → остров переносится на основной монитор, если выбранного нет.
