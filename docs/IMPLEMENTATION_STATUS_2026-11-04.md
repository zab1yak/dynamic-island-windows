## Движок, данные и безопасность

Argos исследован первым. Его обычная поставка требует Python/CTranslate2;
официальные готовые CTranslate2 Windows-бинарники не закрывают Windows ARM64.
Выбран ONNX Runtime CPU 1.31.1 (MIT) и Microsoft.ML.Tokenizers 2.0.1 (MIT),
которые позволяют управляемый tokenizer и готовые нативные Windows x64/ARM64
библиотеки без установки дополнительных инструментов пользователем.

Модели OPUS-MT: `onnx-community/opus-mt-en-ru` и `opus-mt-ru-en`, по 242731178
байт каждое направление. SHA-256 всех шести файлов и immutable revisions записаны
в `TranslationModelCatalog.cs`. Модели скачиваются только по кнопке в каталог
данных; проверяются HTTPS/origin каждого redirect, размер, SHA-256, свободное
место, отмена и атомарное завершение. Нет распаковки архивов или выполнения
загруженного кода. Строгая очистка незавершённых staging-каталогов защищена
межпроцессной блокировкой; чужие каталоги и ссылки не удаляются.

Перед передачей данных в нативный parser повторно проверяются хеши и ссылки.
Нативные сессии создаются только при переводе и освобождаются после него.
Перевод не имеет HTTP-клиента. No-network smoke использует клиент, который
выбрасывает исключение при любой попытке HTTP; оба направления прошли.
Нормальные выход/перезапуск приложения теперь дожидаются отмены команд до
остановки Dispatcher. Аварийное завершение ОС не гарантирует завершения операций;
следующая установка корректно обрабатывает их staging.

История выключена по умолчанию; последние 50 записей и настройка сохраняются
вместе атомарно. В журналах нет введённых текстов или результатов. Существующий
облачный адаптер не зарегистрирован, старые credentials не читаются/не удаляются.

Права/атрибуция: pinned ONNX model cards CC BY4.0, upstream Helsinki-NLP
Apache-2.0; оба источника указаны, установленные модели получают ATTRIBUTION.txt.
MP3 предоставлены владельцем; предыдущая часть беседы фиксирует его подтверждение
прав публичного распространения. Это подтверждение владельца, не независимая
экспертиза происхождения музыки. Telegram — Simple Icons16.0.0 CC0, Mail —
Lucide 1.61.0 ISC. Полные notices и лицензии ONNX/Tokenizers/моделей копируются
в publish. См. `THIRD_PARTY_NOTICES.md` и `Modules.Translator/OFFLINE_MODELS.md`.

## Условия стабильного выпуска

Workflow `Candidate packages` запускает Windows-тесты, реальный x64 engine smoke
с установкой и повтором без загрузки, затем self-contained публикацию x64/ARM64.
Скрипт проверяет наличие звуков/приложения и PE Machine реального onnxruntime.dll.
Кандидаты сохраняются как artifacts; они не попадают в стабильный release/feed.
Дополнительно выполнен реальный native ARM64 smoke с проверкой ProcessArchitecture=Arm64 и запретом HTTP. Наличие DLL само по себе не считается выполнением этой проверки.

Для выпуска остаются: Windows GUI RU/EN, масштабы70/80/90/95/100/110/130%,
DPI100/125/150/200%, left/center/right, все состояния переводчика и настроек;
слышимые Pomodoro/Water (preview, mute, сон, отсутствие дублей), реальные
медиаплееры/уведомления, проверка перехода
установленной0.3.0 на установщики/feeds0.3.1. До этого тег/релиз не создаются.
